## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors for Windows, bundled with a universal loader so you can manage Volt, Synapse Z, Potassium, and Wave from a single application.

### Is XCutors free to use?

Yes. XCutors and all bundled executors are distributed free of charge from this repository.

### Which Windows versions are supported?

XCutors is tested on Windows 10 (version 20H2 and later) and Windows 11. Earlier versions may work but are not officially supported.

### Why do I need to run the loader as Administrator?

Administrator privileges are required so the executor can attach to the Roblox process and inject scripts into the game's Lua environment.

### Can I use XCutors on macOS or Linux?

Not at this time. XCutors and the bundled executors are built exclusively for Windows. You may be able to run them through a Windows virtual machine, but performance is not guaranteed.

### My anticomponent flags the executor — is it safe?

False positives are common with any software that performs memory injection. The executables in this repository are built from source and are not modified after compilation. Always download only from the official Releases page to ensure integrity.

### How do I update the executors?

xccutorsLoader checks for updates automatically on launch. You can also manually download the latest release ZIP and replace your existing files.

### Where can I find scripts to run?

Each executor includes access to a built-in script hub with community-submitted scripts. You can also find scripts on popular Roblox scripting forums and paste them into the executor's editor.

### The injection failed or Roblox crashed. What should I do?

Ensure Roblox is fully loaded in a game before injecting. Restart both Roblox and the executor, run as Administrator, and check that no other overlay or anti-enhance software is interfering. Consult the logs folder for specific error details.

### Can I add my own executor to the loader?

Yes. xcutorsLoader supports custom executor DLLs. Place your executor binary in the 'executors' subdirectory and add a corresponding entry to the loader's config.json file. Refer to the Wiki for detailed instructions.
